# AgentENV integration problems and workarounds

Updated 2026-10-30. Applies to the tested AgentENV **v0.2.4** release and Lewbox's Firecracker-only target. See the [experiment README](README.md) for the complete results and reproduction commands.

**Current decision: RAM snapshots are acceptable.** Capturing memory is no longer an independent adoption blocker. Lewbox exposes stop, start, restart and delete; accepting memory snapshots does not require exposing a pause operation. The earlier disk-only experiments remain useful evidence, but a custom disk-only runtime is now optional.

Credential handling remains a separate requirement: accepting memory snapshots does not establish that snapshots containing imported credentials are acceptable. Gateway cleanup can remove visible files; it has not demonstrated removal of their contents from disk layers or process memory.

Status distinguishes an observed problem, a tested lab workaround, integration work and a validation gap. A proposed fix is not implemented or qualified unless explicitly stated. Plan references identify affected design documents; several still describe AerolVM, multiple runtimes or the superseded prohibition on RAM snapshots. This register does not rewrite those plans or change historical test results.
